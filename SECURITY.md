# Security policy

Report vulnerabilities privately through the repository's **Security → Report a vulnerability** form. Do not put vulnerability details in a public issue. Include only the minimum details needed to reproduce the issue, and do not include real user data, API keys, or other secrets.

Supported versions and response times have not yet been established. Review the code, configure your own secrets and resources, and validate authentication, access control, backups, and deletion behavior before using the service with real data.

Please do not test against `pidgindocs.example.workers.dev`, any other third-party service, or infrastructure you do not own or have explicit permission to assess.
